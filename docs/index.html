ArknightsPatcher · 方舟补丁工具

运行在 iPhone / iPad 上的开源离线 IPA 修补工具，为已解密的《明日方舟》iOS 客户端本地注入 B 服（哔哩哔哩）登录桥接组件，支持内置 2.7.91 基准、导入手工 JSON 配置与 IL2CPP 自动适配。

下载最新 IPA (Releases) 查看 GitHub 源码 参考项目：Arknights-Bilibili-for-IOS

核心特性与性能

极速流式直通 · 15.8 秒完成

采用 ZIP64 流式增量打包，未改动条目直接直通复制；2.79 GB 大体积 IPA 在 iPhone 真机实测约 15.8 秒完成修补与复核。

精准校验（Build 13 优化）

复核全量条目清单与 CRC32，并对所有替换/新增补丁条目执行 SHA-256 校验；跳过冗余的整包 2.8 GB 二次通读哈希，兼顾速度与可靠性。

三层版本适配体系

支持内置已验证 2.7.91 基准、App 内导入新版本手工 JSON 配置（免更新 App），以及未知新版本 IL2CPP 元数据自动定位与布局校验。

原包只读 · 原子暂存

全程不联网、不修改原始 IPA；输出文件先写入临时文件并完成复核后再原子替换，切后台或重启也不易丢失。

B 服桌面图标可选

可自由选择替换为带「B」角标的 B 服专属桌面图标，或保留官服原版图标，方便同机区分多开。

公开参考与开源透明
