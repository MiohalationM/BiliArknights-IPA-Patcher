四步快速上手

全流程在手机上即可完成

1

安装补丁工具

前往 Releases 下载最新未签名 IPA，使用巨魔商店（TrollStore）或常用自签工具安装到设备。

2

选择官服砸壳 IPA

准备好已砸壳的《明日方舟》官服 IPA，在首页点击「选择砸壳 IPA」并等待十几秒。

3

导出并安装游戏

打包完成后导出生成的 B 服 IPA 到「文件」，同样使用巨魔商店或自签工具安装。

4

游戏启动页切 B 服

打开游戏，在启动界面点击右上角悬浮按钮切换到「B服」，即可使用 B 站账号登录。

核心特性

兼顾开箱易用与工程级安全校验

广泛系统兼容

最低支持 iOS / iPadOS 16.0，原生适配 iPhone 与 iPad 横竖屏，兼容 TrollStore、AltStore、SideStore 与 Sideloadly。

流式高速打包与全包校验

原生 ZIP64 流式引擎仅重写改动条目，打包前校验 ARM64 偏移对齐与段界，完成后执行全包 CRC32 复核并原子提交。

版本更新可持续适配

内置 2.7.91 (Build 76) 已验证底座；后续版本在通过字节级兼容性校验后可自动适配，也可导入新版 JSON 配置文件，无需重装 App。

本机离线与隐私边界清晰

补丁工具本身全程离线、不上传文件且绝不改动原 IPA；仅修补后生成的游戏客户端在登录时正常连接官方 / B 站服务器。

可选 B 服专属图标

打包前可自由切换带「B」角标的桌面图标方便与官服区分，或保留游戏原版图标。

内购入口安全拦截

修补后的客户端内已统一拦截应用内充值购买请求，防止误触或走错渠道引发异常。
