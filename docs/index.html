方舟补丁工具 · ArknightsPatcher

无需电脑、不联网、不修改原始安装包。在 iPhone 本机将已解密的官方《明日方舟》IPA 流式重打包为支持 B 服切换与登录的待签名 IPA。

下载最新 IPA (Release) 查看 GitHub 源码 参考上游项目

单遍流式 ZIP64

内置纯 Swift + 系统 zlib 的 Zip64Kit，未改资源 2 MB 分块直通写入，成品导出前 100% 校验 CRC32 与补丁 SHA-256。

数据驱动源码桥接

自维护 ABLoginBridge.dylib 从主包 ABRuntimeProfile.plist 动态读取版本指纹与偏移，告别硬编码 ObjC IMP。

图标自由切换

支持「B 服图标」与「保留原版」一键切换，满足官/B 双端桌面区分或保留原版图标的偏好需求。

三层适配优先级（未来更新无需重装 App）

1
手工导入适配配置（最高优先级） 导入几 KB 的 .json 或 ABRuntimeProfile.plist，按 Bundle ID、版本、构建号与 UnityFramework UUID 精准匹配，新版本无需重新编译 App。
2
内置已验证基准（2.7.91 / build 76） 严格核验全部 6 个宿主二进制 UUID 与加密状态，沿用真机实测通过的 B 服路由与登录流程。
3
本机单 IPA IL2CPP 自动定位（可选开关） 直接解析明文 global-metadata.dat（v27/v29/v31）与 UnityFramework（支持 LC_DYLD_CHAINED_FIXUPS 与 ARM64 ADRP+LDR 双重印证），校验字节级结构体 ABI 通过后方允许导出。
