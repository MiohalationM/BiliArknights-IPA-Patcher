明日方舟 B 服 iOS 补丁工具

BiliArknights IPA Patcher

在 iPhone / iPad 上本地给已解密的《明日方舟》官服 IPA 打上 B 服（哔哩哔哩）登录补丁，生成待签名 IPA。

下载 IPA (Releases) GitHub 源码 参考项目

功能说明

  • 本地离线处理：全程不联网，也不会改动原始 IPA 文件。
  • 速度较快：只重打包改动过的文件，2.8 GB 左右的 IPA 在 iPhone 上大概十几秒完成。
  • 版本适配：内置 2.7.91 已验证配置；后续游戏更新可在 App 内导入手工 JSON 配置，也支持自动解析新版本 IL2CPP 偏移。
  • 可选 B 服图标：支持换成带「B」角标的桌面图标，方便和官服区分，也可以保留原版图标。
